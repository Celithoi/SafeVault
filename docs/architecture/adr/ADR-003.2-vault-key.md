# ADR-003.2 --- Vault Key

**Status:** 🟢 Approved\
**Versão:** 1.0 consolidada\
**Data:** 31/07/2026\
**Autor:** Marcelo Henrique Rocha Cardoso

## 1. Decisão

A Vault Key:

-   é aleatória e gerada por CSPRNG;
-   é criada exclusivamente no cliente;
-   é independente da Master Password;
-   existe uma por Vault;
-   é armazenada no servidor somente em forma protegida
    (`wrappedVaultKey`);
-   é protegida pela Wrap Key;
-   permanece em memória apenas enquanto o cofre estiver desbloqueado.

## 2. Troca da Master Password

Trocar a Master Password não recriptografa todos os itens.

Fluxo:

1.  derivar material antigo;
2.  unwrap da Vault Key;
3.  derivar novo material;
4.  rewrap da mesma Vault Key com a nova Wrap Key.

## 3. Uso

A Vault Key atua como raiz criptográfica do cofre. Subchaves específicas
podem ser derivadas por finalidade quando houver necessidade concreta.

## 4. Decisões Formalmente Aprovadas

-   ✅ Vault Key aleatória e independente da senha.
-   ✅ Geração client-side.
-   ✅ Uma Vault Key por Vault.
-   ✅ `wrappedVaultKey` persistida no servidor.
-   ✅ Wrap Key é responsável pelo unwrap/rewrap.
-   ✅ Troca de Master Password não exige recriptografia integral do
    cofre.
-   ✅ Vault Key plaintext existe somente em memória durante o
    desbloqueio.
