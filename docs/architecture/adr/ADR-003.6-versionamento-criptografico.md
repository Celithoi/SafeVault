# ADR-003.6 --- Versionamento Criptográfico

**Status:** 🟢 Approved\
**Versão:** 1.0 consolidada\
**Data:** 31/07/2026\
**Autor:** Marcelo Henrique Rocha Cardoso

## 1. Decisão

Cada registro criptografado possui `cryptoVersion`, um inteiro crescente
que identifica o conjunto de regras criptográficas aplicável ao
registro.

O SafeVault utiliza **Lazy Migration**:

1.  cliente lê registro em versão suportada;
2.  descriptografa legitimamente;
3.  quando apropriado, recriptografa usando a versão preferida atual;
4.  persiste a nova representação.

## 2. Responsabilidades

-   migração criptográfica ocorre exclusivamente no cliente;
-   servidor não executa descriptografia/recriptografia;
-   registros não são migrados para versão inferior;
-   clientes suportam, no mínimo, versão atual e anterior, salvo revisão
    futura;
-   versões desconhecidas são rejeitadas;
-   conta pode possuir `preferredCryptoVersion`;
-   cada registro preserva sua própria `cryptoVersion`.

## 3. Decisões Formalmente Aprovadas

-   ✅ `cryptoVersion` por registro.
-   ✅ Numeração inteira crescente.
-   ✅ Coexistência temporária entre versões.
-   ✅ Lazy Migration.
-   ✅ Cliente é proprietário da migração criptográfica.
-   ✅ Sem downgrade automático.
-   ✅ Suporte mínimo à versão atual e anterior.
