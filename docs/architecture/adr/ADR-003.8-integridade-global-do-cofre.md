# ADR-003.8 --- Integridade Global do Cofre

**Status:** 🟡 Deferred / Under Discussion\
**Versão:** 0.1\
**Data de registro:** 31/07/2026

## 1. Contexto

AEAD/AAD protege integridade e contexto de um registro individual, mas
um estado antigo criptograficamente válido ainda pode ser reapresentado
para o mesmo item/contexto.

## 2. Problema Pendente

A arquitetura ainda precisa decidir como tratar, se necessário para a V1
ou versão posterior:

-   freshness;
-   replay;
-   rollback;
-   exclusão indevida/ressurreição de estado antigo;
-   integridade do conjunto global do cofre.

## 3. Estado da Decisão

Nenhuma solução foi formalmente aprovada.

Esta ADR permanece uma dependência explícita das decisões de
criptografia e do Core Data Model. `revision`, timestamps operacionais,
soft delete e AEAD **não devem ser tratados como solução criptográfica
de anti-rollback**.

## 4. Regra

-   ⏸ Não inventar mecanismo antes da análise específica.
-   ⏸ Não bloquear artificialmente toda a arquitetura por esta
    pendência.
-   ⚠️ Reavaliar antes de afirmar proteção contra rollback/freshness.
