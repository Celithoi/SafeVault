# ADR-004.1 --- Sessão Autenticada

**Status:** 🟢 Approved\
**Versão:** 1.0 consolidada\
**Data:** 31/07/2026\
**Autor:** Marcelo Henrique Rocha Cardoso

## 1. Decisão

Uma sessão autenticada representa um login em um **cliente/dispositivo
lógico**.

Cada sessão possui:

-   identificador único;
-   ciclo de vida próprio;
-   expiração;
-   renovação;
-   rotação;
-   revogação;
-   associação ao dispositivo lógico.

A autenticação não carrega Vault Key e não implica cofre desbloqueado.

## 2. Credenciais

A arquitetura prevê:

-   credencial de acesso de curta duração;
-   sessão/credencial renovável;
-   rotação;
-   revogação individual.

A escolha concreta entre JWT e token opaco permanece para decisão
posterior no domínio apropriado.

## 3. Decisões Formalmente Aprovadas

-   ✅ Sessão representa login em cliente lógico.
-   ✅ Sessões são individualmente identificáveis e revogáveis.
-   ✅ Credencial de acesso é de curta duração.
-   ✅ Renovação é rotacionável/revogável.
-   ✅ Sessão autenticada não contém Vault Key.
