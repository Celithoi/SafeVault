# ADR-004.4 --- Sessões por Dispositivo

**Status:** 🟢 Approved\
**Versão:** 1.0 consolidada\
**Data:** 31/07/2026\
**Autor:** Marcelo Henrique Rocha Cardoso

## 1. Dispositivo Lógico

"Dispositivo" representa um **cliente lógico**, não necessariamente
hardware físico.

Clientes diferentes no mesmo equipamento podem ser dispositivos lógicos
independentes.

## 2. Identificação

Cada dispositivo lógico possui identificador único não dependente de
nome amigável.

Metadados são mínimos e orientados ao reconhecimento pelo próprio
usuário. Fingerprinting invasivo não faz parte do modelo.

## 3. Revogação

Revogar um dispositivo encerra:

-   sessão autenticada;
-   sessão do cofre;
-   credenciais de renovação;
-   acesso daquele cliente até nova autenticação.

Revogação é isolada ao dispositivo selecionado.

## 4. Limites

A arquitetura pode suportar limites de dispositivos, mas limite
comercial é **política de produto**, não regra arquitetural hardcoded.

## 5. Nome Amigável

Usuário pode atribuir nome amigável sem alterar identidade interna.

## 6. Sessão Ativa

Cada cliente lógico mantém uma sessão autenticada ativa. Nova
autenticação no mesmo cliente substitui a anterior; clientes diferentes
permanecem independentes.

## 7. Auditoria

Eventos relevantes podem ser registrados com minimização de dados,
incluindo autorização, revogação e acessos relevantes.

## 8. Decisões Formalmente Aprovadas

-   ✅ Dispositivo lógico, não hardware físico.
-   ✅ Identificador único.
-   ✅ Metadados mínimos.
-   ✅ Revogação isolada e completa.
-   ✅ Limites futuros são política de produto.
-   ✅ Nome amigável personalizável.
-   ✅ Uma sessão autenticada por cliente lógico.
-   ✅ Eventos relevantes são auditáveis.
